# Figures

Add the original thesis figures to the relevant subfolders:

- `docking_poses/`: PyMOL 3D docking-pose images
- `interaction_diagrams/`: Discovery Studio 2D diagrams
- `plip/`: PLIP interaction figures
- `admet/`: SwissADME and BOILED-Egg figures

Use short, descriptive file names such as:

- `limonene_docking_pose.png`
- `lcarvone_2d_interactions.png`
- `native_ligand_plip.png`
- `boiled_egg_comparison.png`
